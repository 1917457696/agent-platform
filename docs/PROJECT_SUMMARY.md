# 临床学习与问诊训练平台项目总结

## 原项目

原项目是面向中医继续教育的 AI 问答与问诊辅助工具，具备 React 前端、FastAPI API、Agent/RAG、多轮会话、SSE 流式输出、来源展示和安全边界。

## 本次升级

本次将产品叙事从“AI 问诊 Agent”升级为“AI 临床学习与问诊训练平台”，新增稳定的本地病例训练路径：

- 内置胸痛、咳嗽、发热三个结构化合成病例；
- 学员扮演医生，AI 按病例字段扮演患者；
- 通过关键词归一化记录核心问诊维度覆盖；
- 支持学员提交初步判断后再生成训练报告；
- 支持结束问诊并生成四项评分；
- 展示做得好的地方、遗漏问题、遗漏原因和下一步建议；
- 展示 Clinical Reasoning Timeline；
- 保留原有课程 RAG、真实模型问答、流式输出、对话记录和安全边界。

## 当前实现边界

病例训练和评分为前端确定性演示实现，目的是保证现场 Demo 稳定和评分可解释；它不代表临床能力评估，也没有接入真实患者数据。真实模型问答仍要求用户配置自己的 API Key。正式产品还需要服务端训练记录、账号权限、教师审核、内容版本、医学专家审校、脱敏、模型监控和部署治理。

## 后续路线（只做设计，不作为本次交付承诺）

- P1：差异辨证提示、教练式 Hint、学习薄弱点画像和教师端 Bad Case 管理。
- P2：多课程知识空间、真实训练营运营数据、企微/小程序/App 多渠道接入，以及更完整的评测与灰度体系。
- 若引入 LLM 评分，只作为规则评分的辅助解释；病例事实、关键问题覆盖和风险项仍由结构化规则约束，避免让模型自由编造病例信息。

## 现场 Golden Path

进入工作台 → 进入病例训练 → 默认胸痛 → 主动询问位置/性质/时间/诱因/放射/伴随症状/既往史 → 填写初步判断与依据 → 结束问诊并提交 → 展示评分 → 展示遗漏和原因 → 展示临床思维时间轴 → 说明正式版本接入教师审核与训练历史。
